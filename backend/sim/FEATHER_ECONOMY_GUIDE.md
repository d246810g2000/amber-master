# 🏸 羽毛經濟模擬器 (Feather Economy Simulator) 指南

本工具用於模擬 **Amber Badminton 羽毛系統 V1.0** 在長期運作下的經濟健康狀況。透過模擬大量玩家在 52 週內的行為，我們可以預測系統是否會發生嚴重的通貨膨脹，以及「系統規費」回收羽毛的效率。

## 核心模擬參數
您可以在 `feather_economy_sim.py` 的頂部調整以下參數：

- `WEEKLY_WAGE`: 每週三自動領取的羽毛量 (預設 1,000)。
- `SYSTEM_RAKE_RATE`: 系統規費比例 (預設 5%)。這是主要的貨幣回收機制。
- `PLAYER_BONUS_RATE`: 贏球球員的分紅比例 (預設 10%)。
- `ATTENDANCE_RATE`: 玩家出席率。
- `BET_PROBABILITY`: 玩家參與投注的活躍度。

## 如何執行模擬
在終端機執行以下指令：

```bash
python3 backend/sim/feather_economy_sim.py
```

## 觀察指標說明

1. **總貨幣量 (Total Circulation)**: 
   - 若此數值增長過快，代表發放得太多、回收得太少，未來可能需要調高商店價格或增加規費。
   
2. **P90/P10 差距 (財富差距)**:
   - 顯示最富有的 10% 玩家與最貧窮的 10% 玩家之間的差距。
   - 若差距過大 (例如超過 10 倍)，可能需要調低 `MAX_BET` 以保護小資玩家。

3. **回收效率 (Raked)**:
   - 觀察每週回收的羽毛是否能抵銷掉一部分增發的羽毛。

## 規則調整建議
- **若羽毛太多**: 考慮將 `SYSTEM_RAKE_RATE` 從 5% 調升至 8-10%，或調降 `WEEKLY_WAGE`。
- **若大家都不敢投注**: 可能因為賠率太低，考慮調降 `PLAYER_BONUS_RATE`（分紅給球員的錢減少，分給贏家投注者的錢就會增加）。

---
本模擬器僅供測試與平衡參考，實際數據會因球員真實行為而有所變動。
